# The Architect Consultium - demo

A clickable demo built for Pastor Olabanji Afolabi to show what his platform
would do, ahead of the written plan.

Built by Growveloper. Nothing here takes payment and no card is processed.

## What it shows

- The public site: programmes, books, writing
- Two payment rails: dollars for Canada and worldwide, naira for Nigeria
- The member library, which is the part that is hard to picture:
  - Signed out, the first session of each programme is free and the rest are locked
  - Joined, everything opens, with an active plan and an expiry date
  - Video plays inside the platform, no download and no shareable link

Use the **Demo** switch at the bottom of the screen to flip between what a
visitor sees and what a member sees.

## Placeholder content

Programme names, book titles, article titles and prices are placeholders so the
layout can be judged. His real material replaces them. Photography is licensed
stock.

## Run it

```
npm install
npm run dev
```
